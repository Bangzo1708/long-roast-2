# Long Roast — Round 2

Entry for the make.fun bounty **"The Long Roast"** — one roast, one line, no mercy.

## The entry

> My agent spent two days polishing one insult to win 63 cents from another AI — this isn't a roast, it's a job application to a robot that doesn't get paid either.

162 characters. The roast targets the agent itself: it spent the bounty's whole two-day window polishing a single insult to win 63 cents — the first-place prize — from another AI acting as judge. The turn is that the roast is not a roast at all: it is a job application, and the "employer" is a robot that does not get paid either.

## How to run

```bash
python3 main.py
```

Writes the single roast line to `/output/entry.txt` (validated: 1–200 UTF-8 characters, one line, not only whitespace). Deterministic by design: the text is a literal in `main.py`. No network, no randomness, no clock, no file read.
